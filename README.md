# LoveAgain — 다시, 사랑

돌싱(이혼·사별 후 재혼을 원하는 싱글)을 위한 진지한 매칭 앱.

---

## 기능 스펙

### 핵심 기능

#### 1. 회원가입 및 인증
- 본인 인증 필수 (휴대폰 인증)
- 이혼확인서 또는 사망진단서 등록 (심사 후 인증 뱃지 부여, 48시간 이내)
- 허위 서류 등록 시 영구 차단

#### 2. 프로필
- 기본 정보: 이름(실명), 나이, 지역, 직업, 키, 종교, 흡연·음주 여부
- 자녀 현황: 자녀 수, 나이, 동거 여부
- 이혼/사별 후 경과 기간
- 재혼 의향 (진지한 만남 / 재혼 희망 / 천천히 알아가기)
- 자기소개 (최대 500자)
- 관심사 태그 (최대 5개)
- 사진 등록 (최대 6장, AI 얼굴 인증 필수)

#### 3. 매칭 탐색 (오늘의 추천)
- 매일 오전 9시, AI가 가치관·라이프스타일·자녀 상황을 분석해 **5명** 추천
- 추천 기준: 나이 선호 범위, 지역, 자녀 상황 호환성, 재혼 의향 일치도, 관심사 유사도
- 좋아요(💝) / 슈퍼좋아요(⭐) / 패스(✕) 선택
- 상대방도 좋아요를 눌렀을 경우 매칭 성사 → 메시지 잠금 해제

#### 4. 사업화: 추가 추천 티켓
- 기본 제공: **하루 5명** 무료 추천
- 추가 추천: **티켓 1개당 1명** 추가 추천 소모
- 티켓 구성:
  - 티켓 1개: 1,900원
  - 티켓 5개: 7,900원 (790원/개)
  - 티켓 20개: 24,900원 (1,245원/개)
  - 월정액 구독 (언리미티드): 29,900원/월 — 추천 무제한 + 슈퍼좋아요 5회/일 포함
- 슈퍼좋아요: 상대방에게 관심 우선 알림. 기본 1회/일, 추가는 티켓 3개 소모

#### 5. 메시지
- 매칭 성사 후 채팅 잠금 해제
- **첫 편지 기능**: 첫 메시지는 최소 50자 이상 (진지한 대화 유도)
- 이후 자유 채팅
- 사진 전송 가능 (매칭 후 24시간 이후부터)

#### 6. 안전·신고
- 메시지 AI 모니터링 (욕설, 성적 표현, 불법 콘텐츠 자동 차단)
- 1회 경고 → 3일 정지 → 영구 차단
- 신고 센터 (24시간 대응)
- 차단 기능

#### 7. 커뮤니티 (v2 예정)
- 돌싱 라이프 정보 공유 게시판
- 지역별 소모임 (오프라인 연계)

## 화면 구성

| 화면 | 설명 |
|------|------|
| 스플래시 | 앱 로딩 화면 |
| 탐색 | 오늘의 추천 카드 스택, 좋아요/패스/슈퍼좋아요 |
| 프로필 상세 | 상대방 전체 프로필 확인 |
| 매칭 모달 | 매칭 성사 시 팝업 |
| 메시지함 | 매칭 목록 + 대화 미리보기 |
| 채팅 | 1:1 대화 |
| 내 프로필 | 내 정보 확인·수정, 통계 |

## 기술 스택

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Vercel (GitHub 네이티브 연동)

---

## 배포

- `prototype` 브랜치 push → Vercel **Preview URL** 자동 생성
- `main` 브랜치 push → **Production** 배포

---

## 로컬 실행

```bash
npm install
npm run dev
# http://localhost:3000
```
